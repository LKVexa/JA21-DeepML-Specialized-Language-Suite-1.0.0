
# Reading Paths

## Domain author

Start with textbook Chapters 1–6, browse foundation and operator scripts, then use the topic atlas to select a domain package.

## Compiler engineer

Read Chapters 2–6 and 15–20, inspect the grammar and contracts, then compare positive and diagnostic records at each expected stage.

## Scientific or simulation researcher

Read Chapters 3–5, 8, 11, 13, and 15. Focus on units, calibration, uncertainty, causal order, differentiable simulation, and replay.

## Financial modeler

Read Chapters 3, 7, 12, 14, and 19. Keep currency, horizon, scenario assumptions, physical state, and risk judgement separate.

## Robotics or control engineer

Read Chapters 3–6, 10, 12, 15, and 20. Treat actuation as an explicit authority boundary; declaration-only examples are not device commands.

## Certification reviewer

Read Chapters 18–22, then work only from the certification subset after the implementation and ordinary test plan are frozen.
