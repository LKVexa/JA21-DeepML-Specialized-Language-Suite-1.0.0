
# Conformance and Certification Guide

## Test layers

1. Grammar and AST conformance
2. Name, type, unit, schema, and adapter conformance
3. Semantic and policy conformance
4. Optimization and lowering equivalence
5. Runtime validation and replay
6. Certification holdout evaluation

The source corpus contains 1,000 certification holdouts across seven safety topics. The 1,000-script teaching pack includes 100 representative holdouts. Freeze implementation behavior before full holdout evaluation, record prior exposure, and interpret a pass as correct rejection with the expected stage and diagnostic—not successful execution.
