# DeepML Specialized Student Workbook

Use the 1,000-script catalog to select programs and record every source ID used.

## Exercise 1: The Specialized Language as a JA21 Suite

**Primary task:** Trace ten records from source through AST, semantics, validation, R12, and MCRT.

**Evidence to submit:**

- Selected script IDs and paths
- Source and semantic hashes
- Expected compiler/runtime stage
- Units, shapes, horizons, frames, calibration, constraints, or authority profile
- Observed or modeled result
- Diagnostic, operator, and kernel identity
- R12/MCRT fields affected
- Replay state, uncertainty, and limitations

**Reflection:** What would make this result reproducible and interpretable in a second compiler or domain runtime?
