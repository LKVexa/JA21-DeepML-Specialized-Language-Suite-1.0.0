
# JA21 Specialized Publication System

## Visual character

The suite uses a quiet institutional language: generous spacing, short Windows-safe paths, strong hierarchy, evidence tables, restrained mathematical notation, and consistent navigation. The intended feeling is a research atlas rather than a raw data dump.

## Information colors

The tokens are conceptual and may be implemented by any air-gapped JA21/JAXD renderer:

- **Obsidian:** primary text and compiler evidence
- **Ivory:** reading surface
- **Cobalt:** domain identity and navigation
- **Copper:** calibration, provenance, and caution
- **Jade:** admitted positive evidence
- **Crimson:** diagnostic and certification rejection
- **Violet:** R12/MCRT and 8S relations

## Layout principles

1. One primary claim per section.
2. Put identity and evidence before interpretation.
3. Separate source, semantics, compiler, runtime, and judgement visually.
4. Use tables for comparison and code blocks for exact source.
5. Place limitations beside results, not in a distant disclaimer.
6. Preserve printability and offline readability.
