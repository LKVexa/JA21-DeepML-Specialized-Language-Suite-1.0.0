
# Release Notes — JA21 DeepML Specialized Language Suite 1.0.0

## New standalone publication

- Reconstructed the uploaded 102-document corpus wrapper into its source tree.
- Normalized all 10,000 examples into a clear technical record architecture.
- Published twenty 500-record shards and a 10,000-row navigation index.
- Curated 1,000 source-faithful scripts with all-topic and all-tier coverage.
- Separated 7,875 positive, 1,125 ordinary diagnostic, and 1,000 certification-holdout roles without altering the original record class.
- Added a 22-chapter textbook, twelve-week curriculum, workbook, instructor guide, starter project, reading paths, domain architecture map, and publication design system.
- Promoted grammar, compiler/runtime contracts, semantic operators, R12/MCRT schema, and conformance assets into a navigable standalone specification layer.
- Added offline inspection, structural validation, manifests, checksums, and Windows-safe paths.

## Compatibility

The source language identity remains `deepml.specialized` version `0.3`. Publication version 1.0.0 describes this standalone suite and does not imply a new native compiler version.

## Known limitation

Native compiler and runtime execution were not available. Expected results remain corpus-modeled until verified against a conforming implementation.
