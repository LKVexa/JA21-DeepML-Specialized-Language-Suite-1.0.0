# JA21-DeepML-Specialized-Language-Suite-1.0.0

Explore domain units, adapters, and validation constraints with JA21 DeepML Specialized. The 10,000-record corpus, 1,000 source scripts, 22-chapter textbook, and offline learning tools span 42 topics and six tiers. Use examples, diagnostics, and language contracts to study specialized toolchains with transparent qualifications on expected outcomes.

The JA21 DeepML Specialized Language Suite collects source material for exploring domain units, adapters, precision, and validation constraints in specialized language profiles. It is intended for educators, domain-language researchers, compiler authors, and developers planning how domain semantics should connect to a checked base language.

The collection includes 10,000 normalized technical records, twenty navigable shards, 1,000 source-faithful .deepml scripts, and a 22-chapter textbook. Forty-two topics and six proficiency tiers cover positive examples, diagnostics, and certification holdouts. A twelve-week curriculum, student workbook, instructor guide, reading paths, domain architecture map, topic atlas, starter project, grammar, semantic operators, and compiler/runtime contracts support both guided study and implementation planning. Offline inspection tools and source-preserving manifests make the published material navigable.

The October 2026 audit adds schema validation, modeled-evidence qualifications, source consistency checks, and metadata-conflict quarantine. Parts of the grammar remain incomplete, and no native compiler or runtime is supplied. Domain execution, target lowering, graphics rendering, financial calculations, robotic actuation, simulation, and replay require independently observed implementation evidence. Units and precision must extend an explicitly checked base profile.

## Corpora and audit records

The supplied corpus layout is preserved under `payload/`. The `audit/` directory and [AUDIT_AND_UPGRADES.md](AUDIT_AND_UPGRADES.md) record source coverage, release changes, and evidence boundaries.

Historical source archives and source manifests remain provenance records. Current publication file hashes are listed in `PUBLICATION_SHA256.json`; licensing changes are recorded in `PUBLICATION_LICENSE_LEDGER.json`.
